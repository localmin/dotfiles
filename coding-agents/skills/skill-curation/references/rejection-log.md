# Rejection log

skill-curation の Phase 2 で評価して **採用しなかった**候補と理由を記録する。
同じ候補を数ヶ月後に再評価する無駄(star が増えた等で)を防ぐための durable な記録。

書式(1候補1ブロック):

```
## <owner/repo/skills/name>
- date: YYYY-MM-DD
- reason: <非冗長 / license 無し / 本文品質 / メンテ停止 / Fit せず など>
- note: <一行。再評価の条件があれば書く>
```
